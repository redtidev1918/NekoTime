## 使用指南

### 基础操作

| 操作 | 说明 |
|------|------|
| **拖动** | 鼠标按住时钟任意位置拖动（需解锁状态）|
| **隐藏** | 双击时钟窗口，或托盘菜单选择"隐藏/显示" |
| **显示** | 托盘菜单选择"隐藏/显示" |

### 托盘菜单功能

- **Theme** - 切换已安装主题
- **Opacity** - 透明度（30% ~ 100%，五档）
- **Scale** - 缩放（0.75x ~ 2.00x，五档）
- **Lock Position** - 锁定/解锁窗口位置
- **Hide/Show** - 隐藏或唤回时钟窗口
- **Layer** - 显示层级（桌面层 / 置顶）
- **Language** - 切换界面语言（简体中文 / English）
- **Reload Themes** - 重新加载主题
- **Open Theme Folder** - 在文件管理器中打开主题文件夹
- **Quit** - 退出应用
